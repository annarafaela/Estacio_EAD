# Guia e FAQ de Estágio e Projeto Final (TCC) — Engenharia - Estácio EAD

Bem-vindo ao repositório de guias, modelos e perguntas frequentes (FAQs) da disciplina de envolvem **Estágio Supervisionado**, **Pré-Projeto** e **Projeto Final** de cursos de Engenharia.

Este material foi elaborado para orientar os alunos quanto às regras institucionais, modelos de relatórios, normas de escrita científica e trâmites de documentação.

---

## Estrutura do Repositório

O repositório está dividido em três grandes pilares: **Estágio Supervisionado**, **Pré-Projeto** e **Projeto Final / Artigo**.
